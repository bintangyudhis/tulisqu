# Tulisqu

Aplikasi produktivitas untuk mencatat dan mengorganisasi materi kuliah. Catatan dikelompokkan per mata kuliah. Pengguna juga bisa mengunggah berkas, menyimpan tautan, dan menyusun tugas harian.

## Fitur

Fitur berikut masih berupa rencana dan belum diimplementasikan:

- Catatan dengan kategori per mata kuliah
- Unggah berkas pendukung seperti PDF, dokumen, dan presentasi
- Penyimpanan tautan referensi di dalam catatan
- Daftar tugas harian

## Teknologi

Rencana teknologi yang akan dipakai:

- Next.js untuk antarmuka web dan API
- Supabase untuk basis data dan penyimpanan berkas

## Status

Proyek dalam pengembangan. Kode utama belum masuk ke repositori ini. Dokumentasi instalasi dan cara menjalankan akan dilengkapi setelah kode tersedia.
